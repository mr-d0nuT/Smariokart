# Super Mario Kart JS v0.1.0

This is the first packaged development release of the browser-based JavaScript reimplementation.

## Included

- 20 Grand Prix courses and 4 Balloon Battle courses
- 8 drivers and 50/100/150cc classes
- Mode-7-style course rendering with a full lower-screen map
- Items, coins, drifting, jumps, hazards, rankings, and results
- Offline double-click play with no build step
- Complete Node.js regression and rendering test suite
