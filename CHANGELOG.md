# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-23

### Added

- First packaged JavaScript/HTML release.
- Twenty Grand Prix tracks across four cups.
- Four Balloon Battle courses with dedicated Battle AI.
- Eight drivers, three engine classes, items, coins, drifting, hazards, rankings, and race results.
- Mode-7-style perspective renderer and full lower-screen course map.
- Offline `file://` support with embedded course data and audio fallback.
- Logic, rendering, strict-canvas, and self-contained distribution test suites.

### Fixed

- Stable title logo rendering.
- Generated-course starting-grid placement and heading.
- Full-width upper-screen Mode-7 sampling.
- Lower-screen map and driver marker coordinate alignment.
- Offline sound-effect paths, including the race countdown.
- Battle Course relocation without Grand Prix gradient data.
